# Area workspace

A small, framework-free application built on the public `@jorisvdmije/map-master`
package: draw and edit areas and routes, place markers, name features,
import/export GeoJSON and save the workspace in the browser. It shows how an
application combines the editor with its own controls, persistence and error
handling.

## Run it

From the repository root:

```sh
npm ci
npm run dev:workspace             # with a freshly packed build of this checkout
npm run dev:workspace:published   # with the published npm release
```

Open <http://127.0.0.1:5174>; add `?basemap=off` to avoid external tile requests.
Both commands copy this folder to a temporary directory outside the repository and
install the library from a package archive, exactly like an external project.
Restart the command after editing the example. Running `npm ci` directly in this
folder fails, because `vendor/map-master.tgz` is generated by the launcher.

To reuse the application in another project, replace the `file:vendor/map-master.tgz`
dependency with `npm install @jorisvdmije/map-master --save-exact` and run
`npm run dev`. Keep the MapLibre worker import and stylesheet.

## Try it

1. Choose **+ Area**, click three or more corners, then **Finish**.
2. Select the area, enter a name and choose **Apply name**.
3. Choose **Edit vertices**, drag a corner and **Apply changes**. Undo/Redo covers
   geometry, names, deletions and complete imports.
4. Choose **Save workspace**, reload the page and check the geometry and name.
5. **Export GeoJSON** for a portable backup. **Import** appends a file as one undo
   step; an invalid feature or duplicate ID rejects the whole file.

## How it works

- `main.ts` creates the map and editor, renders the toolbar and feature list from
  `onChange`, and updates names with `applyTransaction`.
- `storage.ts` stores a versioned envelope in `localStorage` under
  `geo-area-workspace:v1`:

  ```json
  { "format": "geo-area-workspace", "version": 1, "data": { "type": "FeatureCollection", "features": [] } }
  ```

- Saved data is restored with `importGeoJSON`, followed by `clearHistory()`.
- Saving is explicit. The app compares the current export with the last saved
  snapshot to show unsaved changes, and disables saving while a tool is active.
- Unreadable, corrupt or invalid saved data is never overwritten silently: the app
  offers a recovery download and a confirmed discard. A full storage quota keeps
  both the saved copy and the work in memory.
- Before saving, the app checks that no other tab saved in the meantime. This is an
  optimistic conflict check, not a multi-user collaboration system.
- Imports and saved data are limited to 5 MB.

## Tests

`npm run test:workspace` (part of `npm run check`) installs the packed library in
this application and exercises it in Chromium, including the performance budgets.
See [testing](../../docs/testing.md) for the complete list of scenarios and the
published-release and cross-browser variants.
